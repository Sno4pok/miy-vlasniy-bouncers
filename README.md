Welcome to my repository! This is a personal space where I write, structure, and document useful Lua/Luau scripts, game mechanics, and code snippets for **Roblox Studio** development.

---

# 📌 About the Repository

This repository serves as:
- A personal library of reusable game mechanics and modular scripts.
- A sandbox for practicing clean, optimized Luau code (ModuleScripts, ServerScriptService, ReplicatedStorage).
- Code documentation and structural notes for ongoing Roblox projects.

---

# 📁 Repository Structure

1. All scripts not located in folders are in ServerScriptService.
2. The Configs and GameModes folders are located in ReplicatedStorage. The files within them are ModuleScripts that handle core game concepts and cosmetics.
3. The StarterGui folder contains everything related to the UI.

---

# 🚀 Key Modules & Mechanics

1. RoundSys.
Game loop manager handling round timers, spawning, votings etc.
2. MS DataStoreManager.
Safe player data saving and loading system with error handling.
3. LeaderStats.
Creates and manages player leaderboard stats on join.

notes:
The "MS" prefix indicates that it is a ModuleScript.
The "LS" prefix indicates that it is a LocalScript; additionally, all scripts in StarterGUI are local.
If there is no prefix, it is a standard script.
